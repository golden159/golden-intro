# golden personal intro

golden 的个人品牌与个人名片页面，面向技术同行、朋友和社交关注者。

## 当前状态

当前版本仍是静态预览版。品牌名、学校、专业方向和双模式文案已经完成；公开资料草稿已放在 `content/`，头像素材已放在 `assets/avatar-public.jpg`，但这些资料尚未接入 `index.html`，页面暂时继续使用 Golden 品牌图形和资料整理状态。

在真实项目链接、公开账号、邮箱和头像完成页面核对之前，不发布生产版本。

## 技术结构

- 单文件 `index.html`
- 原生 HTML、CSS、JavaScript 与 Canvas
- Node.js 内置测试框架
- 无安装依赖、无构建步骤

## 本地预览

```bash
python3 -m http.server 4173
```

浏览器访问 `http://127.0.0.1:4173/`。

## 自动测试

```bash
node --test tests/*.test.cjs
```

## 正式发布门槛

生产发布前必须同时满足：

1. 提供并核对 3～5 个项目的代码、演示或实验材料链接。
2. 核对公开 GitHub、X、邮箱和微信信息。
3. 确认 GPA 等可选个人信息是否展示。
4. 将已确认的头像、项目和联系方式接入页面。
5. 检查页面不存在原作者个人内容。
6. 完成桌面、平板、手机和减少动态效果检查。
7. 获得用户对最终公开内容的明确确认。
