# golden personal intro

golden 的个人品牌与个人名片页面，面向技术同行、朋友和社交关注者。

## 当前状态

当前版本用于本地预览。品牌名、学校、专业方向和双模式文案已经完成；头像、项目、GitHub、社交账号和邮箱尚未公开，因此页面使用 Golden 品牌图形，并明确显示资料整理状态。

在真实项目、公开账号、邮箱和头像完成核对之前，不发布生产版本。

## 技术结构

- 单文件 `index.html`
- 原生 HTML、CSS、JavaScript 与 Canvas
- Node.js 内置测试框架
- 无安装依赖、无构建步骤

## 本地预览

```bash
python3 -m http.server 4173
```

浏览器访问 `http://127.0.0.1:4173/`。

## 自动测试

```bash
node --test tests/*.test.cjs
```

## 正式发布门槛

生产发布前必须同时满足：

1. 提供并核对 3～5 个项目。
2. 提供公开 GitHub 用户名或决定永久隐藏 GitHub 数据。
3. 提供主要社交账号和公开邮箱，或明确决定不公开。
4. 提供真实头像或确认长期使用 Golden 品牌图形。
5. 检查页面不存在原作者个人内容。
6. 完成桌面、平板、手机和减少动态效果检查。
7. 获得用户对最终公开内容的明确确认。
